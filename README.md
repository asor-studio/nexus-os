# Nexus OS

This project is a web-based application that emulates the functionalities and user interface of a hypothetical operating system called **Nexus OS**. It was created as a practical demonstration of using the `@asor-studio/asor-core` library to build complex, desktop-like web experiences.

## 🚀 Installation

Follow these steps to download and install the project locally:

1. **Clone the repository:**
   ```bash
   git clone <REPOSITORY_URL>
   cd nexus-os
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm start
   ```

The application will be available at `http://localhost:4200/`.
